What changed between conv3d releases. The [full commit history](https://github.com/trebeljahr/conv3d/commits/main) lives on GitHub; this page summarizes user-visible changes.

## Unreleased

### Security

- **A clean install has no high `npm audit` findings.** conv3d now installs sharp 0.35.5. Through v1.0.8 it installed sharp 0.33.5, which has high-severity advisories in libvips, libheif and librsvg. `--optimize` passes your model's textures to sharp, so these advisories apply to asset packs you did not make.
- **5 moderate findings remain.** They are one chain through `fbx2gltf`, and the installed `minimatch` does not contain the code the advisory describes. See [Troubleshooting](/docs/troubleshooting#npm-audit-reports-5-moderate-findings).
- **conv3d no longer installs the gltfjsx package.** It requires sharp 0.33, so conv3d now ships a copy of gltfjsx's parser and loaders. A clean install drops from 303 packages to 208.

### Bulk conversion

- **`bulk` and `tsx-gen` skip macOS `._*` files.** Zips and tars made on a Mac can carry metadata files such as `._model.fbx` beside the real models. conv3d tried to convert them, and the run exited `2` with `does not have any geometry data`. Both commands now ignore them.

### `--optimize` output

- **Skinned `.glb` files keep valid joints.** A Draco-compressed `.glb` whose `JOINTS_0` accessor stores no data was read as garbage, so a one-joint skin could reference joint 1022. It now reads as zeros, as glTF specifies. The output size of these files changes: one test model went from 6,632 to 7,584 bytes.
- **Other output is unchanged.** `.tsx` files and non-optimized `.glb` files are byte-identical to v1.0.8. Optimized `.glb` files have a new `asset.generator` string. Some PNG textures encode a few bytes differently with the same pixels.

## v1.0.8 — 2026-11-02

### npx and project installs

- **`--json` output now parses when you run conv3d through `npx` or a project install.** v1.0.7 fixed `--json`, the `.tsx` header and unparseable `.glb` files for global installs only. On the other two routes, conv3d still printed the gltfjsx header to stdout, wrote local paths into each `.tsx`, and exited `0` on an unparseable `.glb`. All three routes now behave the same.
- **conv3d has no install script.** It no longer runs `patch-package` after install.

### Warnings

- **OBJ warnings no longer break `--json`.** An `.obj` that names a missing `.mtl` file printed a warning to stdout. These warnings now go to stderr.

## v1.0.7 — 2026-11-02

### Bulk conversion

- **`-y` no longer needs `-m` for a folder.** `conv3d bulk ./models --tsx --optimize -y` used to stop with "--modelType / -m is required". When conv3d cannot ask, it now converts every format it finds (`ALL`), as it already did for glob input. Pass `-m` to pick one format.
- **`ALL` stays quiet about absent formats.** A folder of FBX files no longer prints "No GLTF models found" and "No OBJ models found" warnings.

### Generated components

- **The gltfjsx header is back.** Each `.tsx` starts with gltfjsx's "Auto-generated by" credit again, followed by the model's own `asset.extras` (for example author, licence and source) when the file carries them. The header no longer lists input and output file paths, and nothing is printed to stdout, so `--json` output stays one object.
- **Unparseable `.glb` files fail loudly.** A `.glb` that gltfjsx cannot parse used to end the run with exit code `0` and no output. It now appears in `errors[]` and the run exits with `2`.

### FBX materials

- **Phong, Blinn and Lambert materials are no longer metallic.** `fbx2gltf` gives them metallic `0.4` (Phong, Blinn) or `0.2` (Lambert) and a low roughness, so hand-painted packs rendered like polished metal. conv3d now sets metallic to `0` and maps Phong shininess to roughness the way Blender's FBX importer does. A hand-painted character tested before release now comes out at metallic `0` and roughness `0.5`, the same values as its pack's own glTF export. See [FBX texture recovery](/docs/textures#non-metallic-phong-and-lambert-materials).

### FBX on arm64

- **A plain hint instead of a raw spawn error.** On Apple Silicon without Rosetta, and on arm64 Linux, FBX conversion now fails with one line that says what to do and links the troubleshooting page, instead of `spawn Unknown system error -86` or a qemu loader message.
- **`conv3d doctor` reports FBX readiness.** `doctor --json` has a new `fbx` object (`ready`, `binary`, `version`, `hint`), and `ok` is `false` when the bundled FBX2glTF cannot run. The text and `--markdown` reports show the same line.

## v1.0.6 — 2026-05-19

### FBX texture recovery

`fbx2gltf` replaces textures with a 1×1 placeholder whenever the source FBX references a Windows path it can't resolve on macOS or Linux. conv3d now repairs that on the way out:

- **Texture rescue.** When a baked texture is a 1×1 placeholder, conv3d locates the matching image in the FBX's own directory and swaps it back in before writing the `.glb`.
- **Scored source-stem fallback for `seedMissingTextures`.** Quaternius-style packs (generic material name "Material", sibling `<Stem>Texture.png`) used to fail the strict "exactly-one-image-contains-stem" heuristic. Replaced with a scored matcher (exact → "texture" suffix → alpha → digits-stripped → contains) that picks the best unique winner and refuses ties rather than guessing.
- **Per-material composite / suffix / inverse tiers.** Texture-to-material assignment now walks tiered candidates (composite names, common suffixes like `_BaseColor` / `_albedo`, inverse mappings) before falling back to the source-stem heuristic.
- **Bidirectional stem matching with canonical-shortest tiebreak.** When multiple candidate textures score the same, conv3d prefers the canonically shortest name — stable behavior across reruns instead of order-dependent picks.
- **`.bin` sibling resolution.** `.gltf` files that reference an external `.bin` buffer now resolve relative to each gltf's own directory instead of the run's cwd.

### Docs

- **New documentation site.** Migrated from Docusaurus to Next.js 16 + Fumadocs, with a 3D landing hero at [conv3d.trebeljahr.com](https://conv3d.trebeljahr.com).

## v1.0.5 — 2025-03-06

- Fix forgotten `await` in the bulk convert pipeline.
- Fix `lstat` errors when conv3d encountered broken symlinks while walking input directories.

## v1.0.4 — 2025-03-06

First public release on npm. Includes:

- `bulk` — convert a directory of `.fbx` / `.obj` / `.gltf` files to `.glb`.
- `single` — convert one model.
- `tsx-gen` — generate typed React Three Fiber components via `gltfjsx`.
- `doctor` — environment + dependency check.
- Overwrite protection on the output directory.
- Predictable output layout (`glb/`, `tsx/`, `glb-for-web/`) with `--flat` override.
