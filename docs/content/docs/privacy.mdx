This page covers the conv3d command and this site, conv3d.trebeljahr.com.

## Your 3D files

conv3d converts your files on your own computer. The command sends nothing over the network: no error reports, no usage data and no file contents or file names.

This site never reads your files. It has no upload and no file picker.

## Page views

This site counts page views, file downloads and clicks on outbound links with Plausible. Plausible runs on a server that Rico Trebeljahr operates, at plausible.trebeljahr.com. It sets no cookies and does not store your IP address.

## Error reports

When a page on this site hits an error it did not expect, your browser sends a report to the error tracker of this site. With no error, nothing is sent.

A report contains:

- the error message and where in the site's code it happened
- the page address, without anything after the question mark or the `#`
- the addresses, methods and status codes of the last requests the page made, without anything after the question mark
- the version of the site
- the platform, which is always `web`
- the names of your browser and your operating system

A report never contains:

- your name or your email address
- cookies
- anything you typed, such as a search
- a file name, a file's contents or a path on your computer
- a recording of the screen

The error tracker is GlitchTip. It runs on a server that Rico Trebeljahr operates, at glitchtip.trebeljahr.com. No other company receives the report.

Like every request, a report arrives with your IP address. The report itself does not contain it.
